# 榜单数据来源

`seeds.json` 是项目维护的收录清单，功能简介由项目编写。`snapshot.json` 和 `stars.json` 包含从 npm 与 GitHub 获取的公开统计和识别字段。项目的 MIT 许可证适用于项目源码和自写内容。第三方包名、仓库名及统计数据仍按其原始来源使用。

- [npm 下载统计接口](https://github.com/npm/registry/blob/main/docs/download-counts.md)
- [GitHub 仓库 API](https://docs.github.com/en/rest/repos/repos#get-a-repository)
