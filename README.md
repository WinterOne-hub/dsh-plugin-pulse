# 插件风向标 · Plugin Pulse

DeepSeek Harness 社区插件榜单与需求反馈。无需 DeepSeek API Key。
Community plugin rankings and feature requests for DeepSeek Harness. No DeepSeek API key required.

| 榜单 / Leaderboard | 中文 | English |
| --- | --- | --- |
| 最受欢迎 / Popular | 按近 30 天下载量或 GitHub Stars 排名。 | Rank by 30-day downloads or GitHub stars. |
| 插件趋势 / Trending | 看本周下载增长和新增 Stars。 | Track weekly download growth and new stars. |
| 最期待功能 / Requests | 查找或提交功能需求。 | Browse or submit feature requests. |

## 安装与更新 / Install and update

1. 在 Harness 打开「插件 → 添加插件」，粘贴 [安装包地址](https://github.com/WinterOne-hub/dsh-plugin-pulse/releases/download/v0.1.6/dsh-plugin-pulse-0.1.6.tgz)，安装并启用。
   Open **Plugins → Add plugin** in Harness, paste the [package URL](https://github.com/WinterOne-hub/dsh-plugin-pulse/releases/download/v0.1.6/dsh-plugin-pulse-0.1.6.tgz), then install and enable it.
2. 打开侧边栏的「插件风向标」，点击版本号旁的「检查更新」。发现新版后可在 Harness 内安装。
   Open **Plugin Pulse** in the sidebar and choose **Check for updates** beside the version. Install available updates inside Harness.

榜单每日更新。npm 下载统计预留两天等数据补齐。需求提交需要配置服务。
Rankings refresh daily. npm download counts allow two days for data to settle. Submitting requests requires a configured service.

## 开发 / Development

需要 Node.js 24。运行 `npm run check` 验证构建，运行 `npm run preview` 在本地预览。
Use Node.js 24. Run `npm run check` to verify the build and `npm run preview` to preview locally.
